# GuildBook

A real-life RPG character sheet: quests, skill tree, attributes and a gold shop. Fully customizable, installable as a PWA, all data stays in your browser (localStorage).

- Play: https://guildbook.holiday-games.com/
- Install / download: https://guildbook.holiday-games.com/install.html

Static site, no build step. Serve the folder with any static server (e.g. `npx serve .`).
